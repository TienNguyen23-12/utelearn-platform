Danh sách câu hỏi trong đề:
Tải mẫu Excel
Bạn có thể kéo thả biểu tượng hoặc sử dụng các nút mũi tên để thay đổi thứ tự câu hỏi trong đề thi.
Soạn câu hỏi mới
Học viên điền đúng 1 trong các đáp án dự đoán bên dưới là được tính điểm tối đa. Có thể nhập nhiều dòng hoặc phân tách bằng dấu phẩy (,).
Đang tải danh sách câu hỏi...
Tải câu hỏi lên từ Excel
Nhập danh sách câu hỏi hàng loạt bằng file Excel (.xlsx)
Hướng dẫn nhanh 3 bước:
  1. Tải file mẫu Excel chuẩn: Tải file mẫu (.xlsx)
  2. Điền danh sách câu hỏi theo các cột quy định (hỗ trợ 4 loại: Trắc nghiệm 1 đáp án, nhiều đáp án, Đúng/Sai, Điền từ).
  3. Chọn file Excel đã hoàn thiện bên dưới rồi nhấn "Bắt đầu tải lên".
Hệ thống tự động kiểm tra cú pháp và thêm tất cả câu hỏi hợp lệ vào đề thi.
Chỉ chấp nhận file định dạng Microsoft Excel (.xlsx), kích thước tối đa 10MB.
